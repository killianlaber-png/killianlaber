Pen Silhouette

4350PX x 6525PX, Intro to Computer Graphics

A silhouette of a model’s profile view made with the pen tool. While the result is exceptionally simple, the process to get there wasn’t as straight-forwards as one might assume.

It can be hard to realize just how much detail there is to a person’s silhouette until you’re trying to trace it. Hair is the big thing: it’s pretty tricky to trace because it’s the first time in the process where serious decision making is in order. Things get messy if you try to go hair by hair, so it’s up to you as the designer to choose what shapes best represent the full picture and which ones can be done away with.

Created in Photoshop.
